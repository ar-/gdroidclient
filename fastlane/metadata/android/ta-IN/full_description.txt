# இந்த பயன்பாடு என்ன

 சி-டிராய்டு லிப்ரே எஃப்-டிராய்டு பயன்பாட்டு-ரோபோசிட்டரை உலாவலாம். இது அதிகாரப்பூர்வ வாடிக்கையாளருக்கு மாற்றாக உள்ளது.

 # எஃப்-டிராய்டுடன் ஒப்பிடும்போது கூடுதல் அம்சங்கள்

 * பயன்பாடுகளுக்கான மதிப்புரைகள் மற்றும் கருத்துகளைக் காட்டுகிறது
 * பயன்பாடுகளின் நட்சத்திர மதிப்பீடுகள் (5 நட்சத்திரங்கள் வரை) - இயந்திரம் உருவாக்கிய அளவீடுகள்
 * நட்சத்திர மேலோடை நட்சத்திர மதிப்பீடுகளைக் காட்டுகிறது (கிதுப், அறிவிலிஆய்வு, சோர்ச்ஃபோர்ச்)
 * ச்டார்-ராடிங்சை உருவாக்க லிப்ரே தரவின் அடிப்படையில் (சராசரி வெளியீட்டு சுழற்சி நேரம் போன்றவை) அதிக அளவீடுகள்
 * எந்த அளவீடுகள் தங்களுக்கு முதன்மை என்பதை பயனர்கள் தேர்வு செய்கிறார்கள், எனவே ரெப்போவில் 'சிறந்த பயன்பாடு' இல்லை - தற்போதைய பயனரின் பார்வையில் இருந்து ஒரு 'சிறந்த பயன்பாடு' மட்டுமே உள்ளது
 * பயன்பாட்டைப் பார்க்கும்போது 'ஒத்த பயன்பாடுகள்' மற்றும் 'ஒரே வகையின் பயன்பாடுகளை' காட்டுகிறது
 * பயன்பாட்டைப் பார்க்கும்போது 'அதே எழுத்தாளரின் பயன்பாடுகளை' காட்டுகிறது
 * அனைத்து ஆசிரியர்களின் பட்டியலையும், அவர்களின் பயன்பாடுகள் மற்றும் சராசரி நட்சத்திர மதிப்பீட்டைக் காட்டுகிறது
 * பயன்பாட்டின் வலைத்தளத்தைக் காட்டுகிறது - அது 'கிதுபில் ஒரு README கோப்பு மட்டுமே' என்றாலும் கூட
 * புதிய பயன்பாடுகளையும் அண்மைக் காலத்தில் புதுப்பிக்கப்பட்ட பயன்பாடுகளையும் பிரித்ததைக் காட்டுகிறது
 * சிறந்த கண்ணோட்டத்திற்கு அட்டைகளை ஒரே அளவில் காட்டுகிறது
 * அட்டைகளுக்கு மாற்றாக (பழைய எஃப்-டிராய்டு பதிப்புகளைப் போல) அட்டைகளுக்கு மாற்றாக பட்டியல் பார்வையை வழங்குகிறது
 * பயன்பாடுகளை ஆர்டர் செய்வதற்கும் வரிசைப்படுத்துவதற்கும் அதிக சாத்தியங்கள்
 * பயன்பாடுகளைக் குறிக்க 'விண்மீன்' திறன்
 * பயன்பாடுகளை எல்லா காட்சிகளிலிருந்தும் அகற்ற மறைக்கும் திறன்
 * சாதன மொழியை மாற்றிய பின், சரியான மொழிபெயர்ப்பில் (கிடைத்தால்) வகைகளைக் காட்டுகிறது
 * சரியான மொழிபெயர்ப்பில் திரை சாட்களைக் காட்டுகிறது
 * பெரிய திரைகளைப் பயன்படுத்துகிறது: டேப்லெட்டுகளில் காட்டப்பட்டுள்ள கூடுதல் பயன்பாடுகள்
 * நிலையான பணிகளுக்கான பயன்பாடுகளை எளிதாகக் கண்டறிய குறிச்சொற்கள் (மின்னஞ்சல் வாடிக்கையாளர்கள், கோப்பு உலாவிகள், உரை ஆசிரியர்கள்), ஏனெனில் எஃப்-டிராய்டு வகைகள் மிகவும் பரந்தவை
 * நீங்கள் வழக்கமாக கண்டுபிடிக்காத பயன்பாடுகளைக் கண்டறிய 'சீரற்ற பயன்பாடுகளுக்கு' காண்க
 * பயனர் விரும்பும் பயன்பாடுகளைக் காட்டுகிறது (பகுப்பாய்விற்கான பயனர் தரவைத் திருடாமல்)
 * பொருத்தமான பயன்பாடுகளைக் கண்டுபிடிப்பதில் பயனருக்கு உதவுவதற்கும், களஞ்சியத்திலிருந்து கூடுதல் பயன்பாடுகளைப் பயன்படுத்த ஊக்குவிப்பதற்கும் பயன்பாட்டு களஞ்சியத்திற்கு பல வேறுபட்ட பார்வைகளை வழங்குவதை நோக்கமாகக் கொண்டுள்ளது
 * பயன்பாடுகளைப் பற்றிய கூடுதல் தகவல்களைப் பெற, 'பகிர்வு' பயன்பாடுகள் மற்றொரு கடையுடன் (எஃப்-டிராய்டு, யல்ப், அரோரா,…) திறக்கப்படலாம்.
 * வெவ்வேறு தேடல் வழிமுறை, முடிவுகள் போதுமானதாக இல்லாவிட்டால் தேடலைத் தொடர 'கடினமாகத் தேடலாம்'
 * பயன்பாடுகளின் லோகோக்களை எல்லா நேரத்திலும் காட்டுகிறது (பிணைய இணைப்பு சரியாக இருந்தால்)
 * மேலும் திரை சாட்களைக் காட்டுகிறது
 * திரை சாட்களைக் காட்டுகிறது, முற்றிலும், புதுப்பித்த மற்றும் சரியான மொழியில்
 * ஃபாச்ட்லேன் கட்டமைப்பில் இல்லாதபோது, ச்கிரீன் சாட்களைக் காட்டுகிறது
 * புதிய மற்றும் நவீன எளிதில் பராமரிக்கப்படும் கோட்பேச்
 * தீவிரமாக பராமரிக்கப்படுகிறது
 * இன்னும் பல வர

 # எஃப்-டிராய்டுடன் ஒப்பிடும்போது சி-டிராய்டு விசயங்கள் செய்ய முடியாது (இன்னும்)

 * பயன்பாட்டின் பழைய பதிப்பைக் காட்டவும் அல்லது நிறுவவும்
 * உள்ளக ரெப்போவை உருவாக்கவும், பயன்பாடுகளை 'அருகிலுள்ள' மக்களுடன் பகிர்ந்து கொள்ளுங்கள் அல்லது ஊடலை வழியாக பயன்பாடுகளைப் பகிரவும்
 * எஃப்-டிராய்டு ரெப்போவை விட பிற களஞ்சியங்களைச் சேர்க்கவும்
 * சலுகை பெற்ற நீட்டிப்பைப் பயன்படுத்தவும் (முடிந்தது, ஆனால் நீட்டிப்பு இன்னும் சரிசெய்யப்படவில்லை), சி-டிராய்டு கவனிக்கப்படாத நிறுவல்களை வழங்க வேரூன்றிய சாதனங்களில் ரூட் அனுமதிகளைப் பயன்படுத்தலாம்
 * தானியங்கி புதுப்பிப்புகள்
 * HTTP பதிலாள் அமைப்புகள்
 * சிறந்த பயன்பாடுகளைக் கண்டறிய சி-டிராய்டு வெவ்வேறு வழிகளில் உங்களுக்கு உதவுகிறது, ஆனால் சில சந்தர்ப்பங்களில் உங்களுக்கு இன்னும் 'பகிர்வு' பொத்தானை தேவைப்படலாம், அதை நிறுவ எஃப்-டிராய்டில் அந்த பயன்பாட்டைத் திறக்க. சி-டிராய்டு இப்போது எஃப்-டிராய்டு பயன்பாட்டிற்கு முழுமையான மாற்றாக இல்லை.

 # சி-டிராய்டு மற்றும் எஃப்-டிராய்டின் பகிரப்பட்ட அம்சங்கள்

 * அதே பயன்பாடுகளைக் காட்டுகிறது - ஐயா -டிராய்டு எந்த பயன்பாடுகளையும் சேர்க்காது அல்லது உருவாக்கங்கள், கையொப்பங்களை மாற்றியமைக்காது அல்லது முகவரி களைப் பதிவிறக்காது
